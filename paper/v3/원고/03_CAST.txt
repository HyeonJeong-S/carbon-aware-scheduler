# 3. CAST 시스템

2장에서 본 선행 연구는 리전 용량과 작업 마감 가운데 하나를 양보하거나, 작업이 도착할 때 한 번 배정한 뒤 다시 배정하지 않거나, 탄소와 다른 목적 사이의 가중치를 사람이 정해 고정한다. CAST는 이 셋을 다음과 같이 다룬다. 마감은 반드시 지키고, 용량은 상한을 넘긴 양에 가장 큰 페널티를 부과한다. 1시간 단위의 슬롯마다 대기 중인 모든 작업의 리전과 시작 시각을 하나의 선형 계획 문제로 다시 풀고, 이번 슬롯에 시작하는 작업만 확정한다. 탄소와 지연 사이의 가중치는 정해진 규칙에 따라 슬롯마다 고른다. 매 기간 앞으로의 일정 구간을 다시 최적화하고 당장의 결정만 실행하는 이 구조는 생산계획과 모델 예측 제어(MPC)에서 쓰는 롤링 호라이즌(rolling horizon) 방식[13–15]이다.

## 3.4 스케줄러

스케줄러는 작업의 시작 시각을 고른다. 슬롯 t가 시작하는 정각에 아직 시작하지 않은 작업을 모아 대기 작업 집합 Q를 만든다. 그 슬롯 안에 제출될 작업도 정각에 미리 알려진 것으로 가정해 함께 넣는다.

작업 j의 시작 후보는 현재 슬롯에서 i 슬롯 뒤의 시각이다. i=0은 이번 슬롯에 시작하는 것으로, 정각과 제출 시각 가운데 늦은 때에 시작한다. i≥1은 슬롯 t+i의 정각에 시작한다. i는 마감 안에 끝낼 수 있는 마지막 시작 시각과 예측 구간 24시간 가운데 이른 쪽까지 둔다. 제출된 슬롯에서만 시작할 수 있는 작업을 연기 불가 작업이라 하며, 이 작업과 마지막 시작 시각까지 1시간이 남지 않은 작업은 i=0만 갖는다.

시작 후보의 탄소 비용은 그 시각부터 실행하는 동안의 예측 탄소집약도 평균을 슬롯 t 예측 전체의 최댓값으로 나눈 값이다.

[식 5]

Ĉ_r^(t)(t+i, d_j)는 슬롯 t에 나온 예측으로 구한, 리전 r에서 t+i부터 d_j 동안의 평균 탄소집약도다. 이번 슬롯의 첫 한 시간은 예측 대신 실측값을 쓴다.

스케줄러는 리전별 실행 현황으로 남은 용량을 센다. 이미 시작한 작업 수 n_r과 새로 배정될 작업 수의 합이 상한을 넘으면, 넘은 만큼이 초과량 z^A가 된다.

[식 6]

(j, i) ∋ κ는 작업 j를 i 슬롯 뒤에 시작했을 때 시각 κ에 실행 중임을 뜻한다. 이번 슬롯에서는 작업이 시작하는 순간마다 세며, 정각과 이번 슬롯 작업들의 제출 시각을 모은 집합이 U_t다. 미래 슬롯은 슬롯마다 한 번 센다. 연기 불가 작업은 도착한 슬롯에서 바로 실행해야 하므로, 연기 가능 작업(Q^def)의 미래 계획은 cap_r − ρ_r 이하로 제한해 예비 용량 ρ_r을 남겨 둔다. z^B는 이 한도를 넘긴 양이다.

[식 7]

대기 시간의 상한은 마감이 정하며, 비용이 같은 후보 사이에서는 일찍 시작하는 쪽을 고른다(3.5절).

x_jri는 작업 j를 리전 r에서 i 슬롯 뒤에 시작하게 두는 변수이고, 식 (10)은 한 작업을 한 자리에만 배정한다는 뜻이다. 페널티는 M_A ≫ M_B ≫ 1로 두어 상한, 예비 용량, 탄소와 지연 순으로 우선한다. M_B는 가장 긴 실행 시간(시간 단위)의 2배로 두되 10보다 작지 않게 했고, M_A는 M_B의 100배다. 마지막 항은 비용이 같은 후보 사이에서 일찍 시작하는 쪽을 고르게 하며, ε은 10⁻⁴다.

변수를 0~1 연속으로 두고 선형 계획법(LP)으로 푼다. 용량 제약과 배정 제약이 함께 있어 해가 늘 정수로 나오지는 않으므로, 정수가 아닌 해가 나온 슬롯만 정수 계획법(MILP)으로 다시 푼다. 그런 슬롯은 3.9%였다. 풀고 나면 i=0인 작업만 확정해 실행 현황에 반영하고, i≥1로 정해진 작업은 다음 슬롯에서 새 예측으로 다시 배정한다.

실행 시간이 제출 시점에 알려져 있다고 가정하면 이 배정은 세 가지 성질을 갖는다. 마감을 넘기는 후보가 없으므로 마감 위반이 없다. 슬롯마다 마지막 시작 시각까지 남은 시간이 1시간씩 줄어 결국 i=0만 남으므로 무한히 연기되는 작업이 없다. 초과 변수가 있어 배정 문제는 늘 해를 가진다.

## 3.6 가중치 규칙

α는 슬롯마다 정한다. 후보 α 11개(𝒜 = {0, 0.1, …, 1})마다 배정 문제를 풀고, 그 배정의 실행 시간 가중 평균 왕복 지연 시간 λ̄_α와 예측 배출량 ē_α를 구한다. 두 값을 후보들 사이에서 0~1로 정규화하면 둘 다 가장 작은 이상점(ideal point)이 원점에 오며, 원점에 가장 가까운 후보를 고른다[30].

[식 11]

λ̃_α와 ẽ_α는 정규화한 평균 지연과 예측 배출량이다. 이 규칙을 무릎점 규칙, 고른 점을 무릎점(knee point)이라 부른다. 상한을 넘기는 후보가 있으면 초과가 가장 작은 후보들 안에서 고르고, 거리가 같으면 작은 α를, 모든 후보의 지연이나 배출량이 같으면 α=1을 고른다. 그림 3의 슬롯에서 무릎점은 0.5다.

CAST는 두 가지로 운영할 수 있다. 하나는 슬롯마다 무릎점 규칙으로 α를 고르는 것이다. 다른 하나는 운영 첫 주에 무릎점 규칙을 적용해, 그 주와 같은 평균 지연을 내는 고정 α를 정해 쓰는 것이다. 알고리즘 1은 무릎점 규칙을 쓸 때 한 슬롯의 처리 과정이다.

[알고리즘 1]
Algorithm 1  Per-slot assignment of CAST
Input: cap_r, ρ_r, H, M_A, M_B, ε, 𝒜 = {0, 0.1, …, 1}, forecasts Ĉ_r^(t)(·), job stream
Output: (r(j), τ_j) for all j
 1: Q ← ∅
 2: for t ← 0, 1, 2, … do
 3:   for each j with ⌊s_j⌋ = t do Q ← Q ∪ {j}
 4:   for each j ∈ Q do
 5:     h_j ← ⌊min(D_j − d_j, t + H) − t⌋
 6:     if j is non-deferrable or (D_j − d_j) − t < 1 then h_j ← 0
 7:   for each α ∈ 𝒜 do
 8:     x^α ← LP solution of (6), (7), (9), (10)
 9:     (λ̄_α, ē_α) ← duration-weighted mean latency and forecast emissions of x^α
10:   α* ← knee point by (11) among the candidates with minimum excess over the ceiling; x ← x^{α*}
11:   if x is fractional then x ← MILP solution at α* (HiGHS, relative gap 0.01%)
12:   for each (j, r) with j ∈ Q and x_{j r 0} = 1 do
13:     r(j) ← r; τ_j ← max(t, s_j); add [τ_j, τ_j + d_j) to the running set of r; Q ← Q ∖ {j}
