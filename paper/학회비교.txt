조사로 구체 수치를 못 채운 항목이 제일 많다.

1. TKIPS (정보처리학회논문지, 한국정보처리학회 KIPS)

투고료·게재료 공지: https://kips.or.kr/bbs/sn/article/1688

- KCI 등재: 옛 KTCCS·KTSDE 둘 다 등재지, 2024.1 TKIPS로 통합. 통합판 자체의
  KCI 등재 상태는 KCI 포털(kci.go.kr)에서 "TKIPS" 또는 "정보처리학회논문지"로

- 논문지 성격: 컴�터·통신시스템+소프트웨어·데이터공학 전 분야. 검색으로 확인된
  게재 사례 중 "GPU 워프 스케줄러", "분산 처리 시스템", "엣지 컴퓨팅 태스크
  마이그레이션" 등이 있어 시스템/스케줄링 계열 논문과 주제 적합성은 있는 편.
  다만 "그린컴퓨팅/탄소인지" 관련 게재 이력은 이번 조사로 못 찾음(확인 불가).

- 심사기간: 확인 불가.
- 투고 양식: 확인 불가(사이트에 템플릿이 있을 것으로 추정되나 이번 조사로

2. KTCP (정보과학회 컴퓨팅의 실제 논문지, 한국정보과학회 KIISE)
──────────────────────────────────────────────
공식 URL: https://www.kiise.or.kr/ (학회) / https://journal.kiise.or.kr/ (투고시스템)
투고규정: https://www.kiise.or.kr/academy/main/getContent.fa?content_no=17&MENU_ID=060200

- KCI 등재: 등재(KCI 포털에 별도 서지ID 확인됨, sereId=A00398).
- 논문지 성격: "학계와 산업 간 교류 증진, 문제 해결 중심 연구 장려. 소프트웨어
  또는 컴퓨터 시스템 설계·구현, 소프트웨어 도구 개발, 컴퓨팅 시스템·데이터의
  평가·분석"이 대상 — CAST처럼 "실제로 만들어서 실측 데이터로 검증한 시스템
  논문"과 성격이 잘 맞는다고 판단됨. 다만 그린/탄소 컴퓨팅 게재 사례는 확인 불가.
- 분량 규정: 단편논문은 5면 이내. 일반논문 기본 쪽수는 명시된 걸 못 찾음(확인 불가,
  다만 게재료가 6쪽까지/7~8쪽/9쪽이상 3단계로 나뉘는 걸 보면 6쪽이 사실상
  기준선으로 보인다).
- 게재료(면수 차등):
    1~6쪽: 쪽당 15,000원
    7~8쪽: 쪽당 30,000원
    9쪽 이상: 쪽당 50,000원
    단편논문: 편당 100,000원
  추가 조정: 비회원 저자 포함 시 기본료 +50% / 연구비 지원 문구 포함 시 +10만원
  / 연구비 없음 명시 시 −20% / 게재 시기 조정 요청 시 +30만원.
- 심사료: 일반논문 50,000원(6주 소요) / 초청·단편 50,000원(3주) / 2개월보장긴급
  500,000원(2주).
- 투고 양식: 국문/영문 요약, 참고문헌 영문 표기 등 형식 규정은 확인했으나 구체
  워드 템플릿 파일 링크는 이번 조사로 못 찾음(확인 불가) — journal.kiise.or.kr
  투고 시스템 안에 있을 가능성 높음.

투고규정: https://ki-it.or.kr/homepage/custom/summisregul

- 논문지 성격: 확인 불가 — 이번 조사로 게재 분야·이력을 구체적으로 못 살펴봤다.
  학회명 자체는 "정보기술" 전반을 표방해 범위가 넓은 것으로 보이나, 클라우드/
  스케줄링/그린컴퓨팅 게재 이력은 별도 확인 필요.
- 분량 규정: 일반논문 기본 쪽수 명시 못 찾음(확인 불가). 단편논문은 4쪽 이내.

- 심사기간: 명확한 국문 규정 문구를 못 찾음(확인 불가). 영문 지침에는 "통상

이번 조사로 확인 안 된 것 — 한 곳에 모음
──────────────────────────────────────────────
- TKIPS: 게재료 정확한 금액, 심사기간, 투고 양식/템플릿 링크
- KTCP: 일반논문 기본 쪽수 명문 규정, 템플릿 파일 링크
- JKIIT: 논문지 성격/게재 이력, 일반논문 기본 쪽수, 정확한 심사기간
- JKIICE: 사이트 자체 접근 실패로 생성형AI 고지 재확인·분량 규정·심사기간·
  투고양식 전부 미확인 — 4곳 중 가장 구멍이 많다. 사용자가 investigate 하거나
  다른 세션이 재시도 권장.
- 4곳 공통: "그린컴퓨팅/탄소인지 스케줄링" 주제의 실제 게재 이력(과거에 비슷한
  논문을 실었는지)은 이번 조사로 전혀 확인 못 했다 — 각 논문지의 최근 1~2년
  목차를 직접 훑어보는 별도 작업이 필요하다.
